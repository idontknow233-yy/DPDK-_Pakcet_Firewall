# 第一阶段项目任务清单（基础数据面搭建）

## 阶段目标
完成可运行的数据面Primary进程，具备稳定的收发包流程与基础IPv4转发能力，为后续ACL与状态跟踪打下基础。

## 里程碑与验收标准
- 能稳定启动并收发包，支持双口或回环测试
- 基础IPv4解析与转发路径闭环
- 收/发/处理线程模型稳定运行
- 具备基本统计输出与日志定位手段

## 第1周：环境与框架搭建
1. 确认硬件与系统环境
   - 记录网卡型号、NUMA拓扑、CPU核心数量与超线程情况
   - 规划收发与处理线程核心绑定策略
2. DPDK安装与编译
   - 完成DPDK 24.11编译安装与环境验证
   - 编译运行官方示例并记录启动参数模板
3. 网卡绑定与Hugepage配置
   - 完成网卡绑定与驱动切换
   - 配置并验证Hugepage容量与NUMA分配
4. Primary进程工程骨架
   - 初始化EAL与端口探测
   - 建立基本日志与参数解析框架
   - 统一配置结构体与默认参数

## 第2周：线程模型与内存资源
1. 内存池与mbuf配置
   - 定义mbuf数量、缓存大小、NUMA亲和配置
   - 建立初始化与销毁流程
2. 收发线程与队列规划
   - 规划RX/TX队列数量与RSS策略
   - 实现最小收包与发包闭环
3. 处理流水线框架
   - 定义主处理loop结构与包批处理策略
   - 建立pipeline阶段函数框架与统计钩子
4. 线程绑定与性能基线
   - 绑定核心并验证稳定运行
   - 记录基础吞吐与CPU占用基线数据

## 第3周：IPv4解析与基础转发
1. 协议解析模块
   - 解析以太网与IPv4头部
   - 校验基础字段与长度检查
2. 转发与报文处理流程
   - 建立最简路由逻辑（基于静态规则或直连端口）
   - 实现TTL处理与基础错误计数
3. 转发路径连通性验证
   - 完成双口连通与简单转发测试
   - 记录不同包长的转发表现
4. 基础统计输出
   - 统计收包/丢包/转发数量
   - 输出运行时概要信息与异常计数

## 第4周：ACL雏形与统计框架
1. ACL雏形功能
   - 实现最小规则集合（允许/拒绝）
   - 规则加载与运行时更新接口雏形
2. 统计框架完善
   - 端口级、队列级统计
   - 规则命中统计
3. 稳定性与回归验证
   - 长时间运行测试（例如≥2小时）
   - 检查内存泄漏与异常退出
4. 阶段成果整理
   - 输出阶段总结与问题清单
   - 确认第二阶段依赖项准备完成

## 风险与应对
- 驱动或绑定异常：保留已验证的启动参数与替代驱动方案
- 性能波动：优先保证正确性与稳定性，后续统一优化
- 解析错误导致崩溃：加强边界检查与统计告警
