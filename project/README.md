
# DPDK_Packet_Firewall
## 项目简介
**基于DPDK 24.11的高性能IPv4/IPv6双栈状态化包过滤防火墙**，本科毕业设计项目。
本项目采用**数据面与控制面分离架构**，基于DPDK用户态高性能网络编程技术实现，绕开Linux内核协议栈，通过轮询模式收发包、无锁数据结构、多核并行处理等技术，实现万兆级线速转发、精准ACL规则过滤、状态化连接跟踪、路由转发等核心防火墙能力，同时提供CLI命令行控制台与Web可视化管理界面，兼顾高性能与易用性。

### 核心技术栈
- 核心框架：DPDK 24.11 (PMD驱动、rte_eal、rte_ethdev、rte_mbuf、rte_hash、rte_acl、rte_lpm/lpm6)
- 开发语言：C/C++ (数据面+控制面核心)、Python/Go (Web API)、Vue.js (Web前端)
- 编译构建：Meson + Ninja
- 项目管理：Git (遵循定制化分支/Commit规范)

### 项目核心特性
✅ 高性能用户态收发包，支持网卡多队列RSS分流、批量收发包优化
✅ 完整IPv4/IPv6双栈协议解析与转发，支持ARP/ND/ICMP/ICMPv6协议栈
✅ 状态化连接跟踪，基于rte_hash维护TCP/UDP/ICMP百万级并发连接
✅ 高性能ACL规则引擎，基于rte_acl实现复杂规则匹配、黑白名单/五元组过滤
✅ IPv4/IPv6最长前缀匹配(LPM)路由转发，支持静态路由配置
✅ 数据面+控制面分离，基于DPDK共享内存+无锁队列实现进程间通信
✅ 完善的管理能力：CLI命令行控制台 + Web可视化管理界面 + 实时流量监控
✅ 全链路性能优化：大页内存、缓存对齐、硬件卸载、多核流水线处理

## 开发环境要求
### 系统环境
- 操作系统：Ubuntu 22.04 LTS (64位)
- 内核版本：5.15.0+ (建议开启大页内存、IOAT/DMA卸载)
- CPU：x86_64 多核处理器 (支持Intel VT-x/AMD-V，至少4核8线程)
- 内存：≥8GB (建议16GB+)，开启2MB/1GB 大页内存
- 网卡：支持DPDK PMD驱动的网卡 (Intel 82599/XL710/X710 等，10Gbps最佳)

### 依赖组件
- DPDK：24.11 稳定版 (已编译安装，配置环境变量 RTE_SDK/RTE_TARGET)
- 编译工具：gcc 11+/clang、meson 1.0+、ninja 1.11+
- 依赖库：libnuma-dev、libpcap-dev、pthread
- Web依赖：Node.js 18+、npm/yarn、Python3.10+ (可选)

## 编译与运行步骤
### 前置准备
1. 开启系统大页内存、绑定网卡到DPDK驱动、配置环境变量
2. 确认DPDK 24.11已正确安装并配置 `RTE_SDK` 和 `RTE_TARGET`

### 编译命令
```bash
# 进入项目根目录
cd ~/DPDK_Packet_Firewall
# 创建编译目录并编译
meson build
ninja -C build
# 编译完成后，可执行文件存放在 build/ 目录下
```

### 运行项目
```bash
# 运行数据面主进程 (核心防火墙进程)
sudo ./build/dpdk_packet_firewall -l 0-3 -n 4 --no-pci
# 运行控制面进程 (CLI+Web API)
sudo ./build/control_plane
```

> 注：-l 指定绑定的CPU核心，-n 指定内存通道数，根据自身硬件调整即可。

## 核心功能模块说明
### ✅ 数据面核心模块 (dataplane/)
1. 高性能收发包：基于rte_ethdev的轮询模式，批量收包(rte_eth_rx_burst)、批量发包(rte_eth_tx_burst)，支持多队列RSS分流
2. 双栈协议解析：完整解析IPv4/IPv6/TCP/UDP/ARP/ND/ICMP协议，做合法性校验与异常包丢弃
3. 状态化连接跟踪：基于rte_hash实现五元组到连接状态的映射，rte_timer实现超时连接自动清理
4. ACL规则过滤：基于rte_acl编译黑白名单、五元组、网段规则，实现线速规则匹配与包过滤
5. LPM路由转发：基于rte_lpm/rte_lpm6实现IPv4/IPv6路由表查询，支持静态路由配置与转发
6. IP分片重组：处理IPv4/IPv6分片包，防范分片攻击，保证规则过滤的完整性

### ✅ 控制面核心模块 (controlplane/)
1. CLI控制台：基于rte_cmdline实现交互式命令行，支持规则/路由/配置的增删改查
2. 进程间通信：基于rte_ring无锁队列实现数据面与控制面的配置同步、状态上报
3. Web API：提供RESTful接口，支持前端页面的可视化配置与监控
4. 配置管理：实现配置文件的解析、验证、版本化管理，保证配置一致性

### ✅ Web管理模块 (web/)
- 前端可视化界面：提供防火墙状态监控、ACL规则管理、路由配置、流量统计图表
- 后端服务：转发前端请求到控制面，实现配置下发与状态采集

## 注意事项 (毕业设计开发/运行必看)
1. 运行项目必须使用 **sudo** 权限，DPDK需要权限访问网卡、大页内存、PCI设备
2. 运行前务必开启大页内存，否则DPDK性能会大幅下降，甚至无法运行
3. 网卡必须先绑定到DPDK的vfio-pci/uio_pci_generic驱动，才能被项目识别
4. 开发时建议按「模块化迭代」：先完成数据面基础转发，再逐步添加ACL、连接跟踪、路由等功能
5. 编译报错优先检查DPDK环境变量配置、meson编译配置文件、依赖库是否安装完整
6. 所有项目文档、配置文件、资源均已纳入Git版本管理，请勿提交编译产物、日志、临时文件
